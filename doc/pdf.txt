*pdf.txt*  Read PDFs inside Neovim                                     *pdf.nvim*

`nvim file.pdf` shows the PDF's pages in the window, drawn with iTerm2's
inline image protocol. Needs Neovim 0.12+, iTerm2 and a `python3` with PyMuPDF
(`pip install pymupdf`).

1. Keys                                                       |pdf.nvim-keys|
2. Comments                                               |pdf.nvim-comments|
3. Commands                                               |pdf.nvim-commands|
4. Setup                                                     |pdf.nvim-setup|

==============================================================================
1. Keys                                                        *pdf.nvim-keys*

In a PDF's window:

  `j` `k` <Down> <Up>, wheel      scroll down / up, on to the next or previous
                                page past its end
  `h` `l` <Left> <Right>          scroll left / right
  `n` `p` <Space> <BS>            next / previous page
  <PageDown> <PageUp>
  `gg` `G` <Home> <End>           first / last page
  `+` `=` `-`                       zoom in / out
  `w`                             fit the page's width (what a PDF opens with)
  `0`                             fit the whole page
  click                         on a comment: show its text; elsewhere: mark
                                a spot for the next comment
  drag                          select the text from there to the mouse
  `c`                             comment on the text selected, else at the
                                spot marked, else the top left of what shows
  <Esc>                         let go of the spot and the selection
  `C`                             open or close the comments list

A count works: `3n` is three pages on, `2+` zooms in twice.

The wheel scrolls the window under the mouse: the page when over it, from any
window, and the other windows as usual. The rest of the keys act in the PDF's
window, so go to another (CTRL-W h, CTRL-W l, or a click) to type there.

Splitting a PDF's window (CTRL-W v, CTRL-W s) gives an empty window beside the
page, to take notes in, rather than the page twice; `:vsplit notes.md` opens
the file. `split_empty = false` keeps the page in both. The keys are set
per action in `keys` (|pdf.nvim-setup|).

==============================================================================
2. Comments                                                *pdf.nvim-comments*

Comments are the PDF's own notes (text annotations), saved in the file, so
Preview, Skim and Acrobat show them too; any annotation with text counts. The
page shows them where they sit.

Drag over text to select it (it shows inverted, and the message line has
it), then `c` comments on it: the comment is saved as a highlight of that text,
with the comment as its note. A click without a drag marks a spot instead;
a click on a comment shows its text.

Skim draws comments from other programs but shows their text only once they
are its own: File > Convert Notes. That moves them out of the PDF into Skim's
notes, where pdf.nvim does not see them; Preview and Acrobat show them as
they are.

`C` or |:PdfComments| opens a list of them beside the page, edited like a
file. A comment is a line, `p{page} #{id}  {text}`, and indented lines after
it go on with its text: >
  p1 #1960  change this text to change the comment
  p3 #1963  a comment over
      more than one line
  p2 a new one on page 2
  a new one on the page shown
<
Change a comment's text, delete its lines, or add a line without an `#{id}`,
then `:w` saves it all into the PDF. A new one goes on the text selected on
its page, else at the spot last clicked on it, else at the top left of what
the window shows, else of the page.
Changing the `p{page}` moves one to that page. Lines starting with `"` are
hints. <CR> on a comment shows it in the PDF's window.

==============================================================================
3. Commands                                                *pdf.nvim-commands*

                                                                *:PdfPosition*
:PdfPosition {across} [{down}]
                        Where a page smaller than its window sits: {across}
                        is `left`, `center` or `right`, {down} `top`, `center`
                        or `bottom`; either can be a fraction from 0 to 1.
                        Without {down}, down stays as it is: >
                          :PdfPosition left
                          :PdfPosition right top
                          :PdfPosition 0.25
<
                        The choice is remembered across sessions (in
                        stdpath('state')/pdf.nvim.json) and wins over
                        `position` in |pdf.nvim-setup|; delete that file to
                        go back to it.

                        A page fitting its window's width (`w`, how it opens)
                        fills the width, so only fitting the whole page (`0`)
                        shows where it sits across.

:PdfPosition            Shows where pages sit now.

                                                                *:PdfComments*
:PdfComments            Opens or closes the PDF's comments list, as `C` does
                        (|pdf.nvim-comments|).

==============================================================================
4. Setup                                                      *pdf.nvim-setup*

`require('pdf').setup({...})` changes any of these (the defaults): >lua

  require('pdf').setup({
    python = 'python3',   -- one with PyMuPDF
    scale = 2,            -- render at twice the screen size (retina)
    view = 'width',       -- open fitting the page's width; 1: the whole page
    split_empty = true,   -- a split of a PDF's window starts empty
    smooth = true,        -- scroll by moving the page whole rows, drawing
                          -- only the rows that come in
    position = { 'right', 'center' },  -- see :PdfPosition
    scroll = 0.2,         -- a scroll key moves a fifth of the window
    wheel = 0.05,         -- a wheel tick a twentieth (at least a row)
    zoom = 1.25,          -- each zoom step
    comments_width = 40,  -- the comments list's window
    keys = { next = { 'n' } },  -- per action, replaces its keys
    list_keys = { jump = { '<CR>' } },  -- in the comments list
  })
<
The actions in `keys`: `next`, `prev`, `first`, `last`, `down`, `up`, `left`,
`right`, `wheel_down`, `wheel_up`, `wheel_left`, `wheel_right`, `zoom_in`,
`zoom_out`, `fit`, `fit_width`, `point` (the click), `drag`, `release`,
`clear`, `comment`, `comments`.
